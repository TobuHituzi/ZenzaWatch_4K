# ZenzaWatch

Ginzaから独立して単体で動くHTML5版ニコニコ動画プレイヤーです。
Greasemonkeyスクリプトとして動作します。


## ライセンス

`master` から分岐させたコードにライセンスするなら CC0 あるいは WTFPL あたり


## インストール

[dist](/dist) から `*.user.js` を開き raw ボタンを押すことでインストールできます
